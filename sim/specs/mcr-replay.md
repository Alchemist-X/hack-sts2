# W4 mcr-decoder — `replay.mcr` (CombatReplay) decode — index

Decompile paths drop the `MegaCrit.Sts2.Core.` prefix (v0.111.0 tree unless marked v0.107.1 =
`artifacts/knowledge/decompiled-v0.107.1/MegaCrit/sts2/Core/<path>`).

## Feasibility note (2026-11-01)

- One `.mcr` = **one combat**: `RecordInitialState(ToSave())` runs in `Runs/RunManager.cs:670-673`
  (also `:1181-1184`, `:4368-4371`) on every map-point entry, before `AppendToMapPointHistory`
  and before the room is built; `CombatManager.EndCombatInternal` writes it
  (`Combat/CombatManager.cs:1761-1764`), `CleanUp` writes a still-open one (`Runs/RunManager.cs:4654-4657`).
  `replays/latest.mcr` is overwritten every combat, so a session's `native/replay.mcr` holds only the
  run part's **last** combat. Corpus: 723 files, 723 distinct (611 v0.107.1, 41 v0.110.1, 71 v0.111.0).
- Start state = the full `SerializableRun` at map-point entry: seed + per-stream RNG (v0.111: counter +
  xoshiro state; v0.107.1: counters only), deck in save order, relics, potions, HP/max HP, gold,
  ascension, act, floor (= history length + 1), room sets. Complete for seeding, **except the
  encounter**, which is chosen after the snapshot: resolved from the act room set (next normal /
  elite / boss by visited counters, keyed on the last visited coord's map point type), and for `?`
  points by matching the first checksum's monsters; event-spawned fights stay unresolved.
- Checksum states (`NetFullCombatState`, one per `ChecksumTracker` checksum: after each player
  action, turn start/end phases, enemy turn) carry HP / block / powers / piles in game order /
  energy / RNG, but **no intents, no can_play, no costs, no max energy** → they cannot fill a v1
  `pre_state`; converted bundles keep them under `decisions[].oracle.checksum_state` and leave
  `pre_state` null (replayed, final outcome + HP compared). v0.107.1 replays carry almost no
  checksum states (5 of 611 files).

## Corpus result (2026-11-01)

- `replay-info` over the corpus: 723/723 decode, 0 exceptions; 22954 events (14154 play card, 2930 end
  turn, 417 potion, 1183 player choice, 159 hook), 5028 checksum states.
- `replay-convert` → `tmp/diff-v2/mcr`: 0 fully eligible; 6 pass the sim gate (ported content: Ironclad,
  ported encounter + cards, whitelisted relics) — all v0.107.1 without checksum states. Reasons:
  character not Ironclad 695, model table unverified 652 (611 v0.107.1 + 41 v0.110.1), no checksum
  states 606, player choice 466, enchanted deck 371, potion 281, unresolved encounter 61.
  Only 5 v0.111.0 replays are Ironclad.
- Harness (`--include-ineligible`, all 723): 717 skipped by the sim gate, 6 replayed → 6 action
  divergences at decision 0-3 (hand index defaulted to 0 because the hand is unobservable without
  checksums). No sim exceptions.
