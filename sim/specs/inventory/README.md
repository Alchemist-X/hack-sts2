# Content inventory manifests (game v0.111.0)

Mechanical, regenerable inventory of every content model in the decompile tree, for planning the full
port. Generated by `sim/tools/inventory/extract_models.py` (Python 3, stdlib only); never edit the JSON
by hand. Rule truth is the decompile tree
`/Users/Aincrad/dev-proj/hack-sts2/output/server-bootstrap/linux-decompiled/`, cited as
`<ns-dir>/<File>.cs:<line>` with the `MegaCrit.Sts2.Core.` prefix dropped (the same convention as
`sim/CONTRACTS.md`). Every `file` field uses that relative form.

```
python3 sim/tools/inventory/extract_models.py            # regenerate everything here
python3 sim/tools/inventory/extract_models.py --check    # validate only (exit 1 on problems)
python3 sim/tools/inventory/spotcheck.py --kind cards -n 10
python3 -m unittest discover -s sim/tools/inventory -p 'test_*.py'
```

Output is deterministic (same tree, same bytes). Each kind manifest carries `source_digest`
(SHA-256 over the relative path and text of every scanned file), so a game-version migration shows
which kinds changed.

## Id rule

`ModelDb.GetId(type) = new ModelId(GetCategory(type), GetEntry(type))` (`Models/ModelDb.cs:465-488`):

- `GetEntry(type) = StringHelper.Slugify(type.Name)`; `Slugify` (`Helpers/StringHelper.cs:68-73`) applies
  `CamelCaseRegex` = `([A-Za-z0-9]|\G(?!^))([A-Z])` replaced by `$1_$2` (`:35-40`) to the trimmed name,
  upper-cases (invariant), turns whitespace runs into `_` (`:49-54`) and deletes `[^A-Z0-9_]` (`:56-61`).
  `SnakeCase` (`:63-66`) is the same replacement, lower-cased.
- `GetCategory(type) = ModelId.SlugifyCategory(GetCategoryType(type).Name)`, where `GetCategoryType`
  walks base types up to the class whose base is `AbstractModel` (`Models/ModelDb.cs:470-478`), and
  `SlugifyCategory` strips a trailing `_MODEL` (`Models/ModelId.cs:81-91`). So `StrikeIronclad` is
  `CARD.STRIKE_IRONCLAD`, `WeakPower` is `POWER.WEAK_POWER`, `Neow` (an `AncientEventModel`) is
  `EVENT.NEOW`, `IroncladCardPool` is `CARD_POOL.IRONCLAD_CARD_POOL`.
- `id` in the manifests is the entry (what `sim/CONTRACTS.md` §1 calls the model id); `model_id` is
  `CATEGORY.ENTRY`. Entries collide across categories (`LostWisp` is an event and a relic, `Byrdpip` and
  `PaelsLegion` are a monster and a relic); `model_id` is unique per kind and across the tree.

Python has no `\G`, so `model_ids.camel_case_replace` emulates .NET `Regex.Replace`: `\G` holds only at
the end of the previous match (never after a bump-along), and the first alternative wins. This gives
.NET's odd results for capital runs (`ABCD` → `A_BC_D`, `HTMLParser` → `H_TM_L_PARSER`) where a naive
look-ahead split would give `A_B_C_D`. Verified once against real `System.Text.RegularExpressions`
(.NET 9.0.117) on 1748 names (every model class, every `AbstractModelSubtypes` entry, synthetic edge
cases): 0 mismatches; the tricky vectors are pinned in `sim/tools/inventory/test_inventory.py`.

`registered` is membership in `AbstractModelSubtypes.All` (`Models/AbstractModelSubtypes.cs`, 1660
`typeof` entries, `Count => 1660`), which `ModelDb.AllAbstractModelSubtypes` collects (`Models/ModelDb.cs:66-104`)
and `ModelDb.Init` instantiates (`Models/ModelDb.cs:353`).
Every concrete class in the scanned dirs is registered; abstract intermediates
(`TemporaryStrengthPower`, `TemporaryDexterityPower`, `TemporaryFocusPower`, `DecimillipedeSegment`,
`BattlewornDummyEventEncounter`, `MockCardModel`) are not.

## Common entry fields (every kind)

| Field | Meaning |
| --- | --- |
| `id` | `Slugify(class)` (see above) |
| `model_id` | `CATEGORY.ENTRY`; `null` only if the type does not reach `AbstractModel` (never in practice) |
| `class`, `file`, `class_line` | class name, decompile-relative file, line of the class declaration |
| `base_class` | first base type that is not an interface (`CardModel`, or an intermediate such as `TemporaryStrengthPower`) |
| `is_model` | the type reaches `AbstractModel` |
| `is_abstract` | declared `abstract` |
| `registered` | listed in `AbstractModelSubtypes` |
| `is_mock` | overrides `IsMock => true` (`Models/AbstractModel.cs:70`), lives in a `*.Mocks`/`*.Mock` dir, or the class name starts with `Mock` |
| `is_deprecated` | class name starts with `Deprecated` |
| `hooks_overridden` | every `public override` member name, in source order (properties included, e.g. `Type`, `Rarity`) |
| `protected_overrides` | every non-public override (`OnPlay`, `OnUpgrade`, `CanonicalVars`, `GenerateMoveStateMachine`, `OnUse`, …) |
| `inherited_overrides` | overrides declared by an in-tree intermediate base class and not redeclared here |
| `abstract_model_hooks` | the subset of `hooks_overridden` + `inherited_overrides` that are `AbstractModel` hook virtuals (`hooks.json`) |
| `override_lines` | `{member: line}` of each override declaration (for citations) |
| `hook_scopes` | `abstract_model_hooks` grouped by listener scope from `hooks.json` (`combat`, `run`, `both`, `direct`, `unknown`) |
| `api_calls` | distinct `XCmd.Method` tokens (regex `\b(\w*Cmd)\.(\w+)`, so `Cmd.Wait` is included) plus `Hook.Method` calls, in code only |
| `needs_player_choice` | any choice token: `CardSelectCmd.*`, `RelicSelectCmd.*`, `PlayerChoice*` identifiers, `SignalPlayerChoiceBegun`, `SelectCardsToAddToDeckFromGrid`. Identifiers ending in `PlayerChoiceContext` are excluded: that context is a parameter of nearly every async hook (1720 occurrences) and carries no choice by itself |
| `choice_tokens` | the tokens that set `needs_player_choice` |
| `offers_rewards` | `RewardsCmd.*` tokens (reward screens are a player choice in the run layer) |
| `has_testmode_guard` | file contains an `if (TestMode.IsOff …)` / `if (!TestMode.IsOn …)` block, or the `else` of `if (TestMode.IsOn)` |
| `references_godot_or_ui` | any UI token outside TestMode-guarded blocks (see below) |
| `ui_tokens` | those tokens (whole class) |
| `ui_tokens_in_logic` | UI tokens inside the logic members counted by `lines_logic` (the ones a port must strip or keep in order) |
| `refs` | `{kind: [class, …]}` of model classes this file references (only non-empty kinds; self excluded) |
| `referenced_by_models` | inverse of `refs` over all manifests, as `kind/Class` |
| `rng_usage` | normalized RNG tokens (see below) |
| `dynamic_vars` | `{name: value}` from `CanonicalVars`; `null` if the class has no `CanonicalVars` |
| `dynamic_var_details` | per var: `name`, `type` (`DamageVar`, `PowerVar<WeakPower>`, …), `value`, optional `props` (ValueProp flags) and `extra_args`, `line` |
| `constants` | `const` and `static readonly` fields: literal value, a short expression (≤ 120 chars), or `<expr@line>` |
| `bool_overrides`, `number_overrides` | overridden properties whose expression is a literal (`IsWeak: true`, `StartingHp: "80"`) |
| `lines_total` | physical lines in the file |
| `lines_logic` | rough count of logic lines (below) |
| `logic_members` | `{member: logic lines}` behind `lines_logic` |
| `ported` | the sim defines this id (`ported.json`); always `false` for kinds the sim has no defs for |
| `refs_ambiguous` | optional; type names the resolver could not bind to one kind (none in v0.111.0) |
| `external_refs` | optional, only on entries no pool/act/encounter lists: code references outside the model kind dirs, `file:line` |

Dynamic var names follow the game: a leading string argument, else `typeof(T).Name` for `PowerVar<T>`
(`Localization.DynamicVars/PowerVar.cs:12-13`), else the class's `defaultName` constant
(`Localization.DynamicVars/*.cs`, e.g. `DamageVar` → `Damage`, `CardsVar` → `Cards`). Values keep the source
literal without the `m` suffix (`"8"`, `"1.5"`); non-literal values keep the expression (`"CurrentBlock"`).

Type references (`refs`) come from `ModelDb.<Accessor><X>()`, generic type arguments `<X>`, `typeof(X)`,
`is X`, `as X`, `((X)` casts, fully qualified `MegaCrit.Sts2.Core.Models.<Dir>.X`, and (for powers) any
identifier that is a power class name. A name defined in several kinds binds like C#: the file's own
namespace first, then its `using` namespaces, then a hint from the generic method name (`GetPet<…>` →
monster).

RNG tokens: `RunRng.<Stream>` (any `…RunState.Rng.<Stream>` or `RunRng.<Stream>`; streams are the
`RunRngSet` properties, `Runs/RunRngSet.cs:33-55`), `RunRng.Seed`, `PlayerRng.<Stream>` (`Rewards`,
`Shops`, `Transformations`), `ModelRng.<Method>` (the model's own `Rng`: encounter
`Models/EncounterModel.cs:37`, event `Models/EventModel.cs:399`, monster `Models/MonsterModel.cs:396`;
`ModelRng` alone = passed as a value), `Rng.Chaotic` (static, non-deterministic, UI only),
`RunRngType.X` / `PlayerRngType.X` enum uses, and `local:<var>.<Method>` for lower-case rng variables
(e.g. `local:mapRng.NextGaussianInt` in acts).

UI tokens: `VfxCmd.*`, `SfxCmd.*`, `TalkCmd.*`, `ThinkCmd.*`, `Cmd.Wait`, `Cmd.CustomScaledWait`;
identifiers containing `Vfx` or `Sfx`; `TriggerAnim`, `WithAttackerAnim`, `WithHitFx`, `WithAttackerFx`,
`CreatureAnimator`, `AnimState`, `MegaSpine*`, `MegaSprite`, `MegaSkeleton*`, `MegaSkin`, `ScreenShake`,
`ShakeStrength`, `ShakeDuration`, `PreloadManager`, `SceneHelper`, `ImageHelper`, `HoverTipFactory`,
`NonInteractiveMode`; any `N[A-Z]…` type defined under a `*.Core.Nodes*` namespace (675 such names, e.g.
`NCombatRoom`); and Godot types (`Godot`, `Node`, `Node2D`, `Control`, `Vector2`, `Color`, `Colors`,
`Tween`, `Variant`, `GodotObject`, …; full list in `GODOT_TYPES`).

`lines_logic`: lines in logic members, excluding blank/brace-only lines and async/iterator state-machine
boilerplate (`_003C_003E1__state`, awaiter fields, `AwaitUnsafeOnCompleted`, `GetResult()`,
`IsCompleted` checks, `goto IL_…`/labels, `try`/`catch (Exception)`/`finally`, `Dispose()`, `return;`,
`switch (num)`, `Task.CompletedTask`). Logic members are methods (including overrides, private helpers,
monster move methods, event option handlers), their compiler-generated state machines
(`_003C<M>_003Ed__N.MoveNext` → `M`), lambdas (`_003C<M>_003Eb__…` → `M`) and the `IsPlayable` property;
excluded are constructors, other properties and methods whose name contains a UI word (`Vfx`, `Sfx`,
`Anim`, `Skin`, `Bestiary`, `Camera`, `Visual`, `Portrait`, `Icon`, `HoverTip`, `Speech`, `Dialogue`,
`Texture`, `Color`, `Display`, `AssetPath`, `Description`, `Ambient`, `Music`, `Shake`, `Tween`, `Spine`,
`Node`, `Delay`). Expect ±20 %; use it to rank effort, not to measure it.

## Known extraction limits

- Regex/brace scanning of decompiled text, not a C# compiler. Members are split by brace/paren depth after
  masking comments and literals; it relies on ILSpy formatting (one top-level type per file).
- Property values are only recorded when the expression is a literal; anything computed lands in
  `dynamic_fields`, `*_raw` or `constants` as text and must be read at the cited line.
- `refs` sees type names, not runtime data flow: a model chosen at runtime from a pool or by id string
  is not a reference; hover-tip-only mentions (`HoverTipFactory.FromCard<X>()`) are.
- `needs_player_choice` is token based. Choices made through other screens (event option menus, reward
  screens, `KnowledgeDemon.IChoosable` cards, potion targets) show up in `options_count`, `offers_rewards`
  or not at all.
- `combat_relevant` / `run_relevant` are mechanical (hook scope, room-type test, consulted-by). A `both`
  hook counts for both even if one context cannot occur for that model.
- `lines_logic` is heuristic (see above). `options_count` counts construction sites.
- Pool membership ignores unlock state: `GetUnlocked*` epoch filters (`unlock_gates`) and
  `ActModel.GenerateRooms` epoch filters on events are not applied.
- `external_refs` scans non-model namespaces for the bare class name in code (strings excluded), so it can
  include unrelated members that happen to share the name (e.g. `Osty` in `TargetType.Osty`).

### Classified schema (`sts2sim.inventory.classified/v2`)

Envelope: `schema`, `kind`, `content_kind`, `game_version`, `generated_by`, `requirements_catalogue`, `batches`,
`tier_legend`, `schema_fields` (the meaning of every normalised field), `kind_baseline` (requirement keys every
entry of the kind needs, not listed per entry), then the classifier's own envelope fields; cards add the unified
`port_batch_legend` and `port_batch_prerequisites` (the slice schemes are kept as `legacy_*`). Entries keep the
raw-manifest identity fields (`id`, `model_id`, `class`, `file`) and the classifier's semantic fields
(`mechanics`, `rng_streams`, `ascension_sensitivity`, notes, ...), plus:

| Field | Meaning |
| --- | --- |

| `kernel_requirement_notes` | the classifier's free-text requirements, kept for reading |
| `dependencies` | `{requires, reads, co_port}` of `{kind: [id]}`: applied / created / summoned / offered models; read or type-tested only; definitions that call each other |
| `prompts` | `ChoicePromptKind` records (`HandSelect`, `HandUpgrade`, `PileSelect`, `ChooseCard`, `SimpleGrid`, `DeckUpgrade`, `DeckTransform`, `DeckEnchant`, `DeckRemove`, `DeckGeneric`, `RewardsGrid`, `Bundle`, `CardReward`; `sim/CONTRACTS.md` B1): `kind`, `entry`, `site`, `opened_by`, `via`, `pile`, `min`, `max`, `require_confirm`, `can_skip`, `cancelable`, `context`, `filter`, `cite`, `notes`. `via` names the applied power, spawned monster or offered relic whose own prompt it is. 155 records, 33 of them indirect |

### version-deltas.json

The union of every classifier `version_delta_v107` flag (status other than `same`) and the diff gate's mechanical
diff (`corpus-inventory.json` `version_diff_v0_107_1_vs_v0_111_0`: `content_files`, `version_exclusive_content`,
`engine_files`), plus the content files with a unique edit that `scripts/version_delta.py` found and both
missed (`triage.py` `MANUAL_VD`, read by hand), each entry triaged:

| Triage | Meaning |
| --- | --- |
| `changed` | a single-player run can observe the difference (values, effects, prompts, pool members, odds), or a game model (not a test mock) exists in one tree only; models no single-player run can meet keep their classifier's verdict and carry `single_player_reachable: false` |
| `refactor_only` | no single-player run can observe the difference: decompiler style, renames, UI/VFX, history logging, branches that run only with other players, pool members filtered out in single player, test mocks, IL-recovered arrays equal to v0.107.1 |
| `unknown` | flagged but not adjudicated |

Entry fields: `key` (`<kind>:<Class>`), `kind`, `class`, `id`, `model_id`, `delta_type` (`modified`, `added`,
`removed`), `single_player_reachable` (false for test mocks, `MultiplayerOnly` cards, powers only such content
applies, relics whose `IsAllowed` needs more than one player; `single_player_note` says which), `files` (path in each tree), `classifier` (file, status, note), `diff_gate` (`flagged` plus its value,
enum and call differences), `sources` (`both`, `classifier`, `diff_gate`, `version_delta`), `triage`, `basis` (`classifier`,

`artifacts/knowledge/decompiled-v0.107.1/MegaCrit/sts2/Core`), `evidence_method`; pools add `members_added`,
`members_removed`, `members_multiplayer_only`; removed models add `referenced_by_v0.107.1`.

Counts: 546 content entries, `changed` 172, `refactor_only` 374, `unknown` 0 (503 modified, 40 added, 3 removed;
233 flagged by both sources, 249 by a classifier only, 36 by the diff gate only, 28 found only by
`scripts/version_delta.py`: 27 `refactor_only`, `MusicBox` `changed`; docs/version-delta-demo-2026-11-01.md). The 21 files the diff gate flags

touches no content entry triaged `changed` or `unknown` with `single_player_reachable: true`; engine entries need
