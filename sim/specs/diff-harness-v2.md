# Diff harness v2 — index (W4 harness-v2)

Code: `sim/Sts2Sim.Diff/V2/*`; tests `sim/Sts2Sim.Tests/DiffV2Tests.cs` (`Test_DiffV2_*`). Design: `docs/sim-port/design-diff-gate.md`
§4–§6 (H1, H3 combat-at-anchor glue, H4, H5/H6 run screens, H8 chaining, H10 touched counters, H11). v1 path untouched:
without `--v2`/`--baseline`/`--update-baseline` the CLI, `BundleRunner`, `Projection*`, `DiffReport` are byte-identical
(v1 report on the 6-bundle export `cmp`-equal before/after).

```
dotnet run -c Release --project sim/Sts2Sim.Diff -- <dir|file> --v2 [--report out.json] [--baseline diff-baseline.json] [--update-baseline] [--include-ineligible] [-v]
```

Exit: 0 = no hard divergence / error / exception and the ratchet passes; 1 otherwise; 2 = usage, unreadable baseline, no bundle.

- `RunBundleJson.ReadAny` — `bundle_version` 1 → `FromV1` (one `combat` segment, `CombatStart` = the strict v1 `DiffBundle`, lineage = `source.session`, segment id `combat-a<attempt>`); 2 → strict v2 reader (design §5: kind run|combat, source.lineage/provenance, anchors, segments, eligibility). Errors carry JSON paths (`BundleFormatException`); unknown keys listed, not fatal.
- Unreadable segment (W4 replay-combats, cross-edit) — a `BundleFormatException` inside one segment (exporter nulls on ineligible segments: `action: null` for `decision_unresolved`, `deck: null` for `recorder_gap:deck_order`) no longer fails the whole bundle: the segment keeps id/kind/eligibility and `FormatError`; only when the segment is marked `eligible: false` (an eligible malformed segment still fails the bundle, `exporter_bug`); the runner skips it `version_drift` (old-prefix seed) or `exporter_ineligible`, and breaks the chain. A run without `seeding` is accepted only for an `old`-prefix seed (`RunBundleJson.UnknownSeeding`). Before: 12 of 19 exporter-v2 run bundles were rejected whole.
- Run gate (W4 replay-combats, cross-edit) — `game_mode: custom` with `modifiers: []` and no `game_mode_modifiers*` run reason is in scope (the exporter verified the run history's empty modifier list, v1 rule `sim/specs/diff-bundle-exporter.md` §1); other modes and any modifier stay `out_of_scope`. Before: the only eligible v2 segments (`G0G2JMFEYHRS` s2/s3) were skipped.
- Segment checks — kinds `combat|room|map`; decision `index` = position; `screen` ∈ combat, map, rewards, card_reward, shop, rest_site, event, treasure, select; combat segments accept only combat actions; anchors referenced by segments must be listed; ids unique; `sha256` per segment = SHA-256 of its raw JSON (ratchet change detection).
- `V2Action` — the §5 union (`play_card`, `end_turn`, `undo_end_turn`, `use_potion`, `discard_potion`, `choose`, `map_move`, `next_act`, `event_option`, `event_proceed`, `reward_take`, `rewards_skip`, `card_reward_pick`, `card_reward_skip`, `treasure_open`, `treasure_pick`, `shop_buy`, `shop_remove`, `relic_select`, `rest_option`) plus two harness extensions `shop_leave`, `rest_leave` (the union has no leave action; the recorder has `proceed`). Optional decision key `room_entered {room_type, model_id}` (room-entry projection after a `map_move`).
- v1-shaped combat start — `start` with `player` + `deck` (+ `encounter_id` or segment `room_model_id`, `relics`, `rng_offsets`, `potions [{slot,id}]`) is rebuilt as a v1 shell and read by `BundleJson.Read`; gates = `BundleRunner.IneligibleReason` (Ironclad only, `old` seed, unported encounter/card, relic whitelist, exporter verdict); sim = `BundleRunner.CreateSim` + `AddPotionInternal` per start potion (`Entities.Players/Player.cs` add order not replayed: potions are placed after `SetUpCombat`; gap: a potion with a combat-start hook would be missed). An `mcr_initial` anchor with such a start runs as v1 (mcr-decoder output).
- Anchor start — `AnchorLoader.LoadSaveAnchor`: ref relative to the bundle dir, `sha256` check (`anchor_mismatch`), `RunSaveReader.Read`, `RunImporter.CheckSupported` (reasons → skip `content_not_ported`/`out_of_scope`), `RunImporter.ImportState`, pre-finished combat room rebuilt from `SavedRoom` (`Rooms/AbstractRoom.cs:60-78`), `RunSim.FromLoadedState`. Not `RunSim.FromSave`: in this tree `RunSim.FromSave` and `RunImporter.FromSave` call each other (stack overflow, uncatchable). `NotImplementedException` → skip `run_layer_not_ported:*`. Today every real save stops at `CheckSupported` or at the R3 odds stub (`RunImporter.LoadUnknownMapPointOdds`).
- Seed start — `start {"from":"seed","content":"ported_only"|"all","neow":bool,"act1":id}` → `RunSim.NewRun(RunConfig)` (xxh64 only); `neow:false` = `UnlockProfile.All` minus `NEOW_EPOCH`, the game's own no-Neow branch (`Runs/RunManager` `StartedWithNeow` → `EnterAct` opens the map, sim `RunLoop.cs:192-205`). The G3 start once Neow (`EventRoom.EnterInternal`, R5) lands.
- Chaining (H8) — a segment without start/anchor continues the previous segment's `RunSim` when that segment agreed; after a non-agreeing segment it is skipped `segment_after_unclassified_divergence`; with nothing to continue `anchor_missing`.
- Combat replay (`V2Runner.ReplayCombat`) — v1 loop order (terminal check → project → compare → map → step; unobserved `pre_state: null` replayed, not counted; final `outcome`/`final_hp` at index = decision count). Drivers: `StandaloneCombatDriver` (CombatSim) / `RunCombatDriver` (RunSim, `RunAction.FromCombat`; outcome after the run loop clears `rs.Combat` = win unless the player is dead).
- Combat pre_state — a v1 projection (`turn`+`player`) compared by `ProjectionComparer` (unchanged classes) + hard `player.potions [{slot,id}]` when present (§4.2 combat v2 addition); a `select` object compared against the open prompt (`candidates[{id,upgraded}]` hard, `kind/min/max/site_id/picked` soft — §4.2 "hard ids, soft prompt").
- Combat action mapping (H4) — `play_card`/`end_turn` via `BundleRunner.TryMapAction` (v1 semantics) + driver legality; `use_potion` slot + `potion_id` check, `target_combat_id` → monster index else `NoIndex`; `discard_potion` slot; `choose` = one `ChoosePick` per pick (`index` checked against `card_id`/`upgraded`, or the first unpicked option with that id) then `ChooseConfirm` iff the same prompt is still open (else `ChooseCancel` for a skipped cancelable one) — CONTRACTS B1 auto-complete rule; `undo_end_turn` → divergence `out_of_scope` (no sim counterpart).
- Run screen projection (H5, `RunScreenProjector`) — always `screen`, `room {room_type, model_id}`, `player {hp, max_hp, gold, relics[id], potions[{slot,id}], max_potion_slots}`, `deck [{id, upgraded, enchantment{id,amount}}]`; per screen `map {current, next_options[{col,row,type}] (MapTravel.GetLegalMapPoints order), boss_ids, nodes[{col,row,type,children}]}`, `rewards.items[{type, claimed, gold|potion_id|relic_id|cards}]` (set order), `card_reward {cards, alternatives[option id]}`, `shop.entries[{category, id, upgraded, on_sale, price, stocked}]` (`MerchantInventory.AllEntries` order), `rest_site.options[{id, enabled}]`, `treasure {opened, relics}`, `event {id, finished, options[{key, locked, proceed, relic_id}]}`, `select` (prompt), `combat` (v1 projection). Enum names snake_case; ids compared with `CATEGORY.` stripped.
- Run comparison (H6, `RunScreenComparer`) — only keys the oracle carries; ordered lists, `deck` as multiset (order soft); a key the sim does not project → hard with note → class `projection_gap`; soft leaves `title/description/label/text/site_id/picked`, soft `select.kind/min/max`; numbers by decimal value. Screen mismatch → divergence `screen` (`select` ≡ `combat` for an in-combat `choose`).
- Run action mapping (`ActionMapper.TryMapRun`) — `map_move` → `Travel(i)` by coord in the legal list; `reward_take` → `ClaimReward(index)` or first unclaimed reward of `reward_type`/`item_id`; `rewards_skip`/`next_act` → `ProceedRewards`; `card_reward_pick` → `PickRewardCard` (index/card id checked); `card_reward_skip` → `RewardAlternative(Skip)`; `treasure_*` → `OpenChest`/`TakeTreasureRelic`/`SkipTreasureRelic`; `shop_buy`/`shop_remove` → `BuyEntry` by category + item id (+ price check); `rest_option` → `ChooseRestOption` by option id; `event_option`/`event_proceed` → `ChooseEventOption` by `text_key` (else index / the proceed option) or `LeaveEvent` when finished; `relic_select` and run `choose` → prompt picks; out-of-combat potions → `UsePotion(slot,-1)`/`DiscardPotion`.
- Room entry and floor summary — segment `room_type`/`room_model_id` compared at segment start, `room_entered` after its step; `floor_summary` (normalised `MapPointHistoryEntry`) vs `rs.MapPointHistory[floor-1]` (last entry when `floor` absent): `map_point_type`, `rooms[{room_type, model_id, monster_ids, turns_taken}]`, `gold_gained` hard; other keys (`player_stats`, …) soft "not projected" — the sim history has no player stats (R1 gap).
- Triage (`Triage`, heuristic, §6.4) — exception: `NotImplementedException`/unregistered id → `content_not_ported`, else by throwing namespace `harness_bug` (Sts2Sim.Diff) / `port_bug`; state mismatch → `port_bug` candidate; any unported id touched at the divergent decision → `content_not_ported`; unprojected field → `projection_gap`; action mismatch → `port_bug` for prompt/legality, `harness_bug` when the state was observed and agreed, `port_bug` when unobserved; replayed exporter-ineligible → `exporter_ineligible`; skips: character/content → `content_not_ported`, `old` seed → `version_drift`, modes/modifiers/rules_version ≠ game_version → `out_of_scope`, anchors → `anchor_missing`/`anchor_error`/`run_layer_not_ported`; malformed bundle → `exporter_bug`.
- Coverage (H10 oracle side, `CoverageCounter`) — per (area, id): touched decisions (ids in the decision's `pre_state` + action + segment encounter/start relics), agreed decisions, distinct lineages, agreeing lineages, first divergences, `ported`, `agreement_minimum_met` (≥ 3 agreeing in ≥ 2 lineages, §6.3 without the hook clause); `decisions_reached`, `unobserved_rate`. Areas: card, power, relic, potion, monster, encounter, event, enchantment. Sim-side hook counter not done (optional).
- Baseline + ratchet (H11, `Baseline`) — `diff-baseline.json` = aggregates only: per `<lineage>/<segment>` sha256, status, class, compared, agreed decision indices, first divergence; per-area coverage counts. `--baseline f`: missing file → written; present → ratchet: every baseline-agreed (segment, decision) must agree now; a vanished segment with agreed decisions and an agree → non-agree status are violations; changed sha and newly agreeing segments listed. `--update-baseline` rewrites only after a passing check.
- Report v2 (`ReportV2`) — `report_version` 2; `summary`; `by_version.<v>.by_segment_kind.<kind>.by_first_divergence_class.<class>` (count, statuses, ≤ 50 segment keys); `coverage`; `divergences[]` repro (segment, class, kind, decision, field, all_hard, action, `actions_prefix`, oracle/sim projection); `sim_exceptions`, `soft_summary`, `skipped`, `errors`, `ignored_files`, `unrecognized_bundle_keys`, `segments[]`, `ratchet`.
