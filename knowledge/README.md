# STS2 knowledge layers

This directory deliberately separates facts from strategic opinions.

- `source/v0.107.1/` is regenerated by `scripts/export_sts2_knowledge.py`
  from the local stable game assembly/PCK plus exact live ModelDb lookups. A
  record's `source` block points back to its decompiled class and preserves the
  source hash, numeric expressions, upgrade logic, and enemy move state machine.
- `source/v0.107.1/mechanics.jsonl` contains small, fail-closed cross-model
  contracts extracted from the command layer. These cover semantics that are
  not visible from a card caller alone, such as Osty losing accumulated max-HP
  growth when a dead creature is summoned again. Model records also list their
  referenced `*Cmd` methods as transitive dependencies.
- `priors/v0.107.1/necrobinder/` contains dated, cited community judgments.
  These are fallible recommendations with confidence and version-risk fields;
  they never override source facts.

Regenerate facts while an isolated worker is listening on port 15601:

```bash
python3 scripts/export_sts2_knowledge.py --port 15601 --skip-decompile
```

Omit `--skip-decompile` to rebuild the ignored ILSpy source tree under
`artifacts/knowledge/decompiled-v0.107.1/` first.

`source/v0.111.0/` (public-beta build 41cef1ea) was exported offline, without
a live MCP, so every `runtime` is null. The version and commit come from the
build's `release_info.json`. Both exporters accept the flat `ilspycmd -p` layout
as well as `--nested-directories`. zhs text is picked by its PCK path, because
v0.111.0 added zht after zhs:

```bash
python3 scripts/export_sts2_knowledge.py --offline --skip-decompile \
  --release-channel public-beta \
  --decompiled-root artifacts/knowledge/decompiled-9cb4f1ad \
  --output knowledge/source/v0.111.0
python3 scripts/export_sts2_rule_evidence.py \
  --decompiled-root artifacts/knowledge/decompiled-9cb4f1ad \
  --output knowledge/source/v0.111.0
```

`export_sts2_rule_evidence.py` only exports versions listed in its
`REVIEWED_VERSIONS`. To add a version, first re-read every cited file. The
v0.111.0 review changed one check: `AEONGLASS_CYCLE`, where the A10 EBB attack
dropped from 32 to 26.

Query by stable ID or Chinese/English name; facts and community priors remain
separate in the result:

```bash
python3 scripts/query_sts2_knowledge.py SLEIGHT_OF_FLESH
python3 scripts/query_sts2_knowledge.py 感染棱柱 --kind enemies
python3 scripts/query_sts2_knowledge.py BONE_SHARDS
```

The final query returns both the card and the related verified Osty lifecycle
contract. Strategic opinions are never generated from these source facts.
