      项值说明

      全景：真实引擎、离线工具、Sts2Sim

      左边是真实游戏进程，只产生真值；中间是 Python 工具和反编译源码树；右边是 Sts2Sim。规则流从反编译树到 Core，验证流从人类录像经差分 bundle 回到模拟器逐决策比对。

      run 层：整局是一个大循环

      从开局进幕、选地图点、进房间，到战斗后的奖励，再回到地图，直到幕转换或胜负。每个屏幕都有自己的合法动作；战斗房间里嵌的是 CombatSim，玩家状态共享不复制。

      完整的 Sts2Sim 技术架构页（分层、决策路径、钩子分发、差分闸等）：https://claude.ai/artifact/9roz2JxkbXzfW4d3tat1FQ
