# STS2-Bench：长视界决策基准与双轨自提升（300 字提案）

**底座**：《杀戮尖塔 2》（2025 新作，天然抗语料污染）。三件资产：与真实引擎逐决策差分一致的高速模拟器（705k 决策/秒，已实证 69/69 决策全对齐）；真机考场，成绩可逐步重放认证、无法刷榜；131 局人类 A10 双通道轨迹（可见／特权信息分离）。

**评测**：固定种子配对比较。主榜 A10 通关率（人类锚：录制者 11%、社区均值 17%）；筛选榜 Exam-500 决策一致率；token 成本强制入榜。

**自提升方法 A·记忆进化（权重冻结）**：agent 逐局作战；局后读取审计（死因、资源、失误），写可核对的悔棋注记与策略规则入记忆库；同一模型携新记忆再战。指标：每代记忆在保密种子上的胜率增量与规则存活率（harness 已内建注记与记忆哈希接口）。

**自提升方法 B·训练学生模型（权重更新）**：LLM 任研究员，在模拟器上跑专家迭代——搜索教师生成数据、蒸馏实体编码小网、过差分闸与种子评测、自行修订课程与超参再迭代；人类轨迹作冷启动。产物为 CPU 可部署小模型，真机考场验收。指标：学生 A10 胜率对人类均值 17% 及 LLM 直打成绩的差距。

**交付**：协议 v0.1、一键评测 runner、双赛道基线与公开榜单。
