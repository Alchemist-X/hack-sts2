## 头牌指标（leaderboard 只认这两个数）

| 名称 | 定义 | 用途 |
| --- | --- | --- |
| **A10-IC-50** | Ironclad、A10、固定 50 个保密测试种子上的无 SL 通关率（Wilson 95% CI） | 主榜，整局能力 |
| **Exam-500** | 500 道决策题上与人类专家的 top-1 一致率 | 筛选榜，便宜、可大样本 |

人类锚：录制者本人 A10 ~11%（131 局语料），社区 A10 均值 ~17%。榜上永远显示这两条参考线。

## 赛道 T1：决策考试（Exam）

- **题源**：人类语料决策点（状态 + 合法动作集 + 人类实际选择）。v0.1 出 500 题，
  分层抽样：决策类型（出牌／选目标／结束回合／地图路线／奖励取舍）× 幕 × 角色。
  题库建设前提：`sts2rec canonical` 补 `legal_actions` 导出（backlog 在册）。
- **输入**：agent 可见通道的规范 JSON 状态 + legal_actions 列表（assisted 模式）。
  不含种子、抽堆顺序、RNG 状态。
- **打分**：top-1 与人类一致 = 1，否则 0。报告总分 % + 按决策类型分解。
- **无效输出**：重试 1 次，仍无效计 0 并计入 `invalid_rate`（单列报告）。
- **成本**：tokens/题 必报。
- **诚实声明**：人类选择 ≠ 唯一正确，本分是代理指标；P1 搜索教师就绪后增发
  oracle-regret 版本（同题库，以搜索价值差打分），两版并行报告。

## 赛道 T2：战斗切片（v0.1 可选，sim 内容到位后启用）

- 从人类录像的战斗开局状态（diff bundle 同机制）重放开打。
- 指标：胜率 + ΔHP（相对人类同一战斗的掉血差，HP 效率）。
- 平台：sim（已差分验证的内容范围内）。

## 赛道 T3：整局（Full-Run，主榜）

- **平台**：真实引擎 + STS2_MCP harness。**无 SL**：save&quit 即判该局弃权
  （harness 强制）。
- **种子**：dev 集 10 个（公开，调试用）+ test 集 50 个（保密）。所有 agent
  跑同一组种子（配对比较）。v0.1 轨道：Ironclad A0（入门）与 A10（主榜）。
- **主指标**：通关率 + Wilson 95% CI。
- **副指标**（全部必报）：平均到达层数（删失生存曲线）、通关局平均剩余 HP、
  决策延迟 p50/p95、$/局、tokens/决策、invalid-action 率。
- **采样纪律**：每种子一次通过；best-of-n 必须申报并单列赛道，不与单次混排。
- **工具边界**：adapter 只暴露游戏接口；运行时不得联网检索攻略（harness 不提供
  网络工具）；模型内置知识不设限（抗污染靠 STS2 内容新颖性，另设 probe 实验）。
- **认证（防伪，本 benchmark 独有）**：每局保存种子 + 完整动作流；计分前抽样
  （决赛圈全量）在真实引擎逐决策重放，状态一致才计入。重放机制即差分闸的
  同一套机器。

## 统计功效速查（为什么是这些样本量）

- 区分 11% vs 17% 胜率 @ 80% 功效、α=0.05：非配对约 **500 局/组**；
  同种子配对（McNemar／配对 bootstrap）通常省 2–4×。
- v0.1 现实妥协：粗榜每 agent 20–30 局（只区分数量级差距，CI 会很宽，照实画）；
  决赛圈候选加样到 ≥200 局。Exam-500 不受此限（题目独立，500 题 CI ±~4%）。

## 版本治理

- 游戏更新 → 差分闸回归跑一遍 → 出"规则漂移说明"→ benchmark 小版本号递增。
- 已知先例：v0.107.1 → v0.110.1 连 RNG 种子算法都换了（HashOld → XXH64），
  跨版本成绩永不混排。
