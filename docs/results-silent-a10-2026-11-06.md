## 一句话

从随机初始化起，10 亿环境步把 dev-128 平均通关进度从 0.25（W0）推到 0.44–0.46（A / B），ab-512 端点最高 0.467（A u6564）、
官方终点 A u7664 0.464；**所有评测 0 通关**。离目标（进度 ≥ 0.60、通关率 ≥ 0.10）还差约 0.15 进度，卡在 Act 2 boss。

## 读表前要知道的（方法）

- **进度（protocol v0.2）**：`docs/sts2-bench-protocol-v0.2-2026-11-01.md` §4，唯一实现 `sim/tools/eval/sts2eval/progress.py`。
  胜利 = 1.0；否则 `((a − 1) + min(c, L_a − 1) / L_a) / 3`，`a` = 所在幕，`c` = 本幕已通过的房间数（死亡所在房间不算通过），
  `L_a` = 本幕房间数。所以死在 Act 1 boss ≈ 0.314，进入 Act 2 = 1/3，进入 Act 3 = 2/3；0.44 大约是"Act 2 中段"。
- **95% CI**：均值 ± 1.96·s/√n 的正态近似（协议 v0.2 §4.3）。dev-128 单点的半宽约 ±0.025–0.03，相邻两点差 0.03 以内都是噪声；
  线与线之间的正式比较用逐种子**配对**差（`sts2train compare`，bootstrap 95%），本文件只列各自的均值。
- **种子集**：
  - **dev-128** = `silent-a10-dev-v1`（D1A10SI001–128，128 局 SILENT A10）：训练从不使用的开局（种子流有隔离守卫，
    `docs/diag-2026-11-04/q3-isolation.md`），每 100 update 一次的固定评测（`--eval-at-every 100`，pinned 权重）。
  - **ab-512** = `silent-a10-ab-v1`（TRAIN0-SILENT-4096..4607，512 局）：确认集，只在每段终点（每 500 update）评一次。
  - 盲测集 `silent-a10-blind-v1`（256 局）本轮没有看过，任何评测路径不加 `--allow-blind --purpose` 都会拒绝。
- **loop breaker 开 / 关**：breaker 是评测侧的保护，同一状态重复走过的行会被屏蔽（`docs/diag-2026-11-04/q4-loopbreaker.md`）。
  **greedy-off（关 breaker）是主读数**：它是策略本身的水平。旧谱系 u2225 上 breaker 贡献 +0.120（0.372 → 0.252）；本分支自 C1 起
  加了 UI 循环成本，开 / 关几乎逐局相同（A / B 每一点差 ≤ 0.003）。
- **官方读数**：`scripts/colab/w3m_line.sh` 每段终点（u3564、u4064 … u7564、u7664）的端点评测：ab-512 greedy-off；
  最后一段另加 ab-512 greedy-on 与 dev-128 采样 ×3（`sample_seed 1`，breaker 关）。目录 `runs/<run>/evals/endpoint/u000NNNN-*`。
- **一个 update** = 2048 并行局 × 64 步 = 131,072 环境步；所有线都是 mid 预设（2,904,208 参数，`config.json` `params`）。

## 不一致与注意事项

- **D 带着 harvest**：`docs/round2-plan-2026-11-05.md` 的设计表写 D "与 A 相同，无 harvest"，但 D 从 B 的 checkpoint 续训，
  `w4-d/config.json` 的 `config.harvest` = `boss:1536,elite:512,act2:1024`，train.log 第一段开头有 `self-anchor starts: rings boss 1536 …`。
  所以 D 实际是"B 的配方、熵恒定 0.005"。C（`--macros all`，从同一 checkpoint 续训）是否同样继承 harvest 要在 C 的 config.json 里核对，
  C − D 的配对比较只有在两臂一致时才只差 macros。
- **D 第三段中断**：u8664 之后的训练器在 compiled-vs-eager 数值门（loss 相对误差 2.31e-2 > 1e-2）上退出（`w4-d/status.json`
  `CompiledMismatchError`），保活随之停机；研究日志 00:10 → 00:50 记录了处理（驱动脚本改为重试 + `--compile off`，D 在新运行时上从 ckpt-0008664 续训）。
- **研究日志的个别数字是取整或另一模式**：22:15 条目的 "D u8164 dev-128 0.440" 是 greedy-on（0.4400），greedy-off 为 0.4419；
  "80/128 进二幕"之类的计数只数 `act_reached["2"]`，不含已进 Act 3 的局（B u7664：80 + 2）；14:00 条目里 M 的 "u1264 0.348、u2264 0.389"
  是二次取整，原始值 0.34749 / 0.38846（本文件写 0.347 / 0.388）；23:15 条目的 "D u8500 0.447" 是 greedy-on（0.4470），greedy-off 为 0.4478。
- **采样 ×3 的种子集名**：`repeats.json` 写的是 `silent-a10-dev-s128`，与 greedy 评测的 `silent-a10-dev-v1` 名字不同（同为 dev-128 的 128 局）；
  本文件按 dev-128 处理，未逐局核对。
- 采样 ×3（随机采样动作）比贪心低：A u7664 0.416 对贪心 0.444，B 0.425 对 0.440；贪心是主读数。
- 线 B 的训练期 metrics / episodes（u3064–u7425）在桶里被轮换后的新会话覆盖（交接 20:15）；评测与 checkpoint 完好，本文件只用评测。
