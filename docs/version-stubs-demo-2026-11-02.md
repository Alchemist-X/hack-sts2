# Version work packets demo: v0.107.1 -> v0.111.0 (2026-11-02)

`scripts/version_stubs.py` turns a version-delta manifest into one **work packet per changed, added or removed
content model**, so a game update becomes a list of small, self-contained port tasks. Same tree pair as
[`docs/version-delta-demo-2026-11-01.md`](version-delta-demo-2026-11-01.md); the runner that chains it with the
other steps is in [`docs/version-migration-playbook.md`](version-migration-playbook.md).

```bash
python3 scripts/version_delta.py \
  /Users/Aincrad/dev-proj/hack-sts2/artifacts/knowledge/decompiled-v0.107.1 \
  /Users/Aincrad/dev-proj/hack-sts2/artifacts/knowledge/decompiled-9cb4f1ad \
  --old-version 0.107.1 --new-version 0.111.0 --out tmp/version-delta/v107-9cb \
  --cite-tree /Users/Aincrad/dev-proj/hack-sts2/output/server-bootstrap/linux-decompiled
# version-delta 0.107.1 -> 0.111.0: content 546, kernel 134, out_of_scope 407; 11.2 s
python3 scripts/version_stubs.py tmp/version-delta/v107-9cb/manifest.json --out tmp/version-update/v107-9cb \
  --trimmed-index tmp/version-update/v107-9cb/INDEX-trimmed.md --top 6 --check-skeletons
# version-stubs 0.107.1 -> 0.111.0: 546 packets (new 36, removed 3, unique 279, bulk only 228), 23 skeletons; 2.2 s
# skeleton compile check: 23 skeletons, OK (0 diagnostics)
python3 -m unittest discover -s scripts -p 'test_*.py'    # 53 tests (version_stubs 12, hook_drift 11)
```

## What a packet holds

`tmp/version-update/v107-9cb/packets/<kind>/<ModelId>.md` (git-ignored output):

| section | content |
| --- | --- |
| What changed | one line from the class diff: value edits (`FocusPower 4 -> 5`, `CardRarity Rare -> Uncommon`; numbers first, then enum values), `+hook` / `-hook` (a member named like a sim hook virtual), `+member` / `-member`, `signature X`, `bulk B1 only`; NEW models get base type, constructor values, canonical vars and overrides |
| table | decompiled key, old / new paths, normalised size, changed members, bulk patterns |
| Sim file | the Defs file (or the table file for pools / modifiers); for a removed model the delete-or-`[VersionExclusive]` note |
| Spec lines to update | `sim/specs` / `docs/sim-port` lines whose citation falls in a changed member (line / member / added / removed hits), then the other lines citing the file |
| Tests | the test methods that mention the id, class or sim file, plus the filter command |
| Skeleton + test stub | NEW models without a sim file: the file-per-model convention of the kind (id constant, constructor or `Id` override, canonical vars, overrides with the sim base class's own signatures; card hooks that `CardDef` lacks go on a nested `CardListener`; abstract members filled with `TODO` throws; `[SimExclude]` so nothing registers until ported) and a registration test |
| Decompiled source diff | unified diff of the old and new class text, trimmed to the class, original line numbers |

`--check-skeletons` drops every skeleton into `sim/Sts2Sim.Core/ZzVersionStubsCheck/`, builds Core and removes the
directory again: all 23 skeletons of this delta (16 cards, 7 powers) compile with 0 warnings. The other 13 added
models already have sim files (the sim targets v0.111.0); their packets compare the existing port with the new
decompile instead.

Example packet (`cards/CARD.BIASED_COGNITION.md`, abridged): **What changed:** `FocusPower 4 -> 5`; sim file
`sim/Sts2Sim.Core/Cards/Defs/BiasedCognition.cs`; no spec line cites the changed member (one index line cites the
file); tests `Content_cards_9_1Tests`; diff `-new PowerVar<FocusPower>(4m)` / `+new PowerVar<FocusPower>(5m)`.

The summaries reproduce the hand-read examples of the delta demo: `Relax` `BlockVar 15 -> 16`, `Anticipate`
`UpgradeValueBy 1 -> 2`, `BiasedCognition` `FocusPower 4 -> 5`, `Colossus` `BlockVar 5 -> 4`, `PactsEnd`
`DamageVar 17 -> 18`, `Null` `WeakPower 2 -> 1`, `Alignment` `CanonicalStarCost 3 -> 2`, `Accelerant`
`CardRarity Rare -> Uncommon`, `SilentCardPool` `Card Scare -> Sidestep`. Edits whose meaning is in control flow
(`MusicBox`, `Swift`, `Mirage`) get `edits in <member>` and need the diff.
