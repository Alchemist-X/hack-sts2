6决策时前瞻：在 u2050 上没有显著收益

诚实的确定化（determinized）前瞻：每个克隆重新采样抽牌顺序和所有随机流，从不读取真实的隐藏状态；turn 视野，value+hp 叶子评分，K = 8。与同一 checkpoint（s8a u2050）的贪心在相同的 128 个 dev 种子上配对比较，两者都没有开 loop-breaker。

表格视图：前瞻与贪心
  • 结果：前瞻 0.274 [0.255, 0.292]，贪心 0.282 [0.262, 0.302]；配对差（前瞻 − 贪心）= −0.008 [−0.027, +0.011]，前瞻更好 32 局、更差 40 局、相同 56 局——不显著。
  • 为什么交付贪心 + loop-breaker（0.351 [0.326, 0.376]，0 局卡死）：同一个 checkpoint，只差开不开 loop-breaker，进度就差 0.069（不开时贪心 52 局、前瞻 44 局卡死在循环里）。搜索要先接上 loop-breaker、再换更好的叶子评分（例如新的 win_prob / combat_hp 头）才可能有收益；早先在旧 checkpoint 上同一配置的增益是 +0.015（dev-128，CI 不含 0），也还低于 ExIt 的 +0.02 门槛。
  • 搜索开销：17,414 个搜索决策（占在线决策的 55%），共 344,546 个 env-steps、236,767 次前向；A100 上每个搜索决策 7.7 ms。

注：结果文档和会话记录写的“Δ +0.008 [−0.011, +0.027]，40 更好 / 32 更差”是按“贪心 − 前瞻”方向算出的同一组数。按每局进度重算（la-u2050-dev 与 la-u2050-dev-greedy 的 report.json），前瞻 − 贪心 = −0.008，前瞻更好 32 局、更差 40 局。结论不变：不显著。

checkpoint 为 s8a u2050（07:30 的保底版本，即第 2 段末的 checkpoint，weights 68d3601d9f91672d；u2225 在 10:00 截止前没来得及上真游戏），贪心 + loop-breaker，Silent A10 标准局。

HP 轨迹（每个决策前的 HP，来自 status.log；末点为终局 HP 0）

表格视图：每层第一个决策时的 HP

孪生验证的是什么：真游戏跑在隔离的无头实例里，通过 STS2_MCP 的 eval API 开局；模拟器孪生与它逐决策同步运行，每一步核对楼层、幕、HP、金币、能量、格挡、手牌、敌人、药水、遗物和界面内容。两局都是 0 desync、0 resync，并且与各自的 dry run 逐决策一致——在模拟器里训练出的策略可以原样驱动真游戏。每局各有一次 loop-breaker 介入（休息点用 HEAL 代替重复的 SMITH），胜率头全程约为 0（最大 0.0001 / 0.0004）。修复前的试跑暴露了三处接口差异（事件奖励页退出、无 id 的遗物奖励、升级预览的二次取消），已在 PR #30 的合并 0fa1fa3 中修复。用户的 Steam 安装、存档和录像都没有改动。

9下一步

  1. 战斗专项课程。从战斗快照起步的 combat gym，配更密的战斗奖励。依据：dev-128 上 91/128 局（71%）死于 Boss 或精英，其中 46 局死在第 1 幕 Boss 房；构筑通道已经打开，战斗强度是瓶颈。
  2. 先把价值头做成叶子评分，再谈前瞻 / ExIt。用 value / win_prob / combat_hp 头给前瞻的叶子打分，前瞻增益稳定超过 +0.02 后再做 ExIt 蒸馏。依据：u2050 上前瞻 −0.008（不显著），旧 checkpoint 上 +0.015，叶子评分是限制。
  3. 更长的连续段。两张 A100 各跑 6–8 h。依据：本周期各段 1.3–3.0 h，20 局评测的区间约 ±0.08，小改进需要更长的段和更大的评测集才分得出来。参照：竞品 AlphaDefect 的 NoSL 单模型（Defect A10，v141229）自测胜率 75.1% ± 2.7%，按其版本号推算训练了约 29–46 亿次决策；u2225 累计 2.92 亿 env-steps。
  4. 异步采集。把闲置的 CPU 用于并行采样。依据：s8a 最后一段纯环境吞吐 30,572 env-steps/s，端到端只有 12,723。
