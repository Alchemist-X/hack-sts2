# docs/results：实验台账

`lines-silent-a10.json` 是 Silent A10 训练的**实验台账**（看板 v2 的 `lines` 数据集）：2026-11-04 起跑过或已排定的每条线一行，记录分叉点、相对对照的旗标差、运行时、起止时间、计划与已完成的 update、GPU 小时与估算单位（`gpu_hours × 6.73`）、段终读数 `endpoints`、最佳读数、配对比较 `paired`、结论、停止原因、教训和出处文档（`endpoints` 与 `paired` 是 JSON 字符串）。`line-events-silent-a10.jsonl` 是看板的 `line_events` 数据集，每行一个事件，记录每条线的经过：起跑、段终读数、配对比较、决策、事故、停止和备注，时间是 EST `YYYY-MM-DD HH:MM`。事实（结论、教训、决策时间）取自研究日志、各轮计划、交接文档和编排日志；数字取自桶的只读镜像：`metrics.jsonl` / `evals.jsonl` / `status.json`，段终的 ab-512 取自 `evals/endpoint/*/report.json`，缺失时用 `evals-silent-a10-2026-11-06.json`；配对差取自文档原文。`gpu_hours` 是首末两行 metrics 之间的训练时长：超过 30 分钟的间隔（停机、空转）不计，只按其间实际完成的 update 数 × 中位 s/update 补算。段终之后的端点评测不计入；仍在跑的线按镜像快照计。文档没给的数（例如某个配对区间）留空，不估。**扩展方法**：新线起跑时在 `lines-silent-a10.json` 末尾加一行，`order` 取下一个整数，`status` 填 `planned` 或 `running`，`verdict` 填 `pending`；每次段终、配对、决策或事故时，在 `line-events-silent-a10.jsonl` 追加一行，`line` 用台账里已有的 `id`。线结束后补 `ended`、`updates_done`、`gpu_hours`、`units_est`、`endpoints`、`paired`、`verdict` 和 `lessons`。

校验（在仓库根目录运行；通过时打印行数与事件数）：

```bash
python3 -c "import json,math;L=json.load(open('docs/results/lines-silent-a10.json'));E=[json.loads(x) for x in open('docs/results/line-events-silent-a10.jsonl') if x.strip()];K='id run title hypothesis fork_line fork_update flags control gpu_session started ended status updates_from updates_to updates_done gpu_hours units_est endpoints best_ab512 best_ab512_update best_dev128 best_dev128_update paired verdict stop_reason lessons docs order'.split();ids={l['id'] for l in L};num=lambda v:not(isinstance(v,float) and not math.isfinite(v));assert len(ids)==len(L);assert all(set(l)==set(K) and l['status'] in('running','done','stopped','planned','lost') and l['verdict'] in('adopted','neutral','rejected','stopped','pending') and isinstance(json.loads(l['endpoints']),list) and isinstance(json.loads(l['paired']),list) and all(num(v) for v in l.values()) for l in L),'lines';assert all(set(e)=={'line','time','kind','event','update','value'} and e['line'] in ids and e['kind'] in('start','segment','eval','pair','decision','incident','stop','note') and len(e['time'])==16 and num(e['value']) for e in E),'events';assert all(c['vs'] in ids for l in L for c in json.loads(l['paired']));print(len(L),'lines',len(E),'events OK')"
```
