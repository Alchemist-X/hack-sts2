## 3. 怎么跑

```bash
dotnet build sim/Sts2Sim.sln -c Release                      # 0 警告
dotnet run -c Release --project sim/Sts2Sim.Tests            # 全量约 6 分钟（含 1 万局 soak）；加 " -- Server" 只跑服务器测试
scripts/sim_server.sh            # 构建并后台启动对局服务器（8765），stop / status / restart
python3 sim/tools/play/sim_play.py new --seed PLAY1 --character IRONCLAD --ascension 0
python3 sim/tools/play/sim_play.py show r1 ; step r1 "play 0 -> 0" ; history r1 ; random --runs 10
dotnet run -c Release --project sim/Sts2Sim.Server -- --selftest 300 --content ported_only   # 进程内随机自测
dotnet run -c Release --project sim/Sts2Sim.Bench            # 吞吐 / Clone；run-soak 选项见 BENCH.md
cd sts2rec && uv run sts2rec export-bundles-v2 ../tmp/diff-v2 --sim-core ../sim/Sts2Sim.Core   # v2 bundle
dotnet run -c Release --project sim/Sts2Sim.Diff -- <bundle dir> [--v2] [--report out.json]       # 差分闸
dotnet run -c Release --project sim/Sts2Sim.Diff -- g3 ...   # 整局重放，见 sim/specs/diff-report-w4-run.md
dotnet run -c Release --project sim/Sts2Sim.Diff -- replay-info <file|dir>                        # .mcr 解码
```

接口说明：`sim/PLAY.md`（端点、观测字段、token 语法）、`sim/tools/play/AGENT_PLAYBOOK.md`（给
LLM 代理）。规则真值：反编译树 `output/server-bootstrap/linux-decompiled/`（目录带
`MegaCrit.Sts2.Core.` 前缀，只读、不入库）。人类语料：`~/Library/Application Support/Sts2Recorder/sessions/`（只读）。
稳定的交接文件：`tmp/handoff/`（差分 bundle、W3 分配表、各工作流脚本，git-ignored）。

## 4. 流程约定（用户决定）

- **精简流程**：简报 → 并行所有者（隔离 worktree，先 `git reset --hard <基线>`）→ 单一集成者跑
  自动门（构建 / 测试 / soak / 差分 / 基准）→ 提交。不设对抗校验与审计阶段。
- Fable 编排、工程子代理一律 `model: 'opus'`；**打游戏的试玩代理可以用 Sonnet**。
- Workflow 工具的 `isolation: 'worktree'` 从 `origin/main` 切 worktree，代理必须先 reset 到基线。
- 不提交轨迹 / 存档 / bundle；不改游戏存档（只拷贝）。
