# 线 S："boss 学校"（2026-11-06 15:20 EST 预注册，数据未见）

## 假设

第二关 boss 的瓶颈是"带着弱牌组到达 + 击杀信号太弱"：到达率 ≈ 20%，到达后击杀 ≈ 7%（第一关 79%）；协议里击杀只值 ≈ 1/(3L) ≈ 0.02，价值头在 act 2 近 boss 处斜率 0.5（`docs/diag-2026-11-06/value-calibration.md`）；用策略自己的 boss 入口回放（harvest，线 B）无效；反事实评测（`docs/diag-2026-11-06/what-if-forced-choice.md`）说明无条件强制升级 / 精英更差，构筑修复是慢变量。给策略**像样牌组下的后期经验**并**放大击杀信号**，应当直接提高到达第三幕的比例。

## 预注册判据（u12164，dev-128 greedy、关 breaker；评测永不使用存档）

1. **先行指标**：`act_reached[3]`（= 击杀第二关 boss）的局数。C2 基线 u10200–10400 为 3–6 / 128。采纳：≥ 12 / 128 且 progress 不劣于起点 −0.01；弃用：三个连续评测点 progress < 0.42；其余看 2。
2. 进 boss 时的 HP / 升级 / 遗物（wave-6 字段，`boss_entry`）与 boss 战胜率（到达者中）。
3. 训练期：`save_starts_update`、`boss2_kills`、`boss_bonus_sum`、`save_*` 与 `fresh_*` 分流的进度（学校局与新开局分开看，防止学校局抬高训练进度造成错觉）。
4. ab-512 段终照常（确认集）。

## 风险与已知限制

- 只有 2 局人类对局，牌组多样性低——策略可能学会"那两套牌"的打法而不泛化；需要用户再录 5–10 局到第二 / 三幕的 Silent A10。
- A9 存档在 A9 难度下进行，训练分布略偏易；评估仍是 A10。
- 学校局的回报从存档的 `start_progress` 起算（`progress_gain`），不会混入评估口径。
